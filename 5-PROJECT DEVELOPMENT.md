## Step 3: Create Import Set

Create the Employee Import table using Load Data.

## Step 4: Create Transform Map

Create the Sample Spreadsheet Import Transform Map.


## Step 5: Map Fields

Use Auto Map Matching Fields or Mapping Assist to connect the source and target fields.

## Step 6: Transform Data

Run the Transform Map to transfer the imported data into the Employee Test table.

## Step 7: Configure Coalesce

Set Coalesce to True for the selected field, such as Employee ID.

## Step 8: Create Reports

Create department, location and employee list reports.

## Step 9: Create Dashboard

Create the Employee Analytics Dashboards and add the reports to it.
